# Blinkit Sales Analysis Dashboard (Power BI)

## Project Overview
This project is a Power BI dashboard created to analyze Blinkit sales performance, outlet performance, item types, and customer ratings. The dashboard provides insights into sales trends and outlet performance.

## Problem Statement
The objective of this project is to analyze Blinkit sales data to understand:
- Total sales and average sales
- Sales by outlet size and location
- Sales by item type
- Outlet establishment growth
- Customer ratings and item visibility

## Tools Used
- Power BI
- Power Query (Data Cleaning)
- DAX (Calculated Measures)
- Data Visualization

## Process
1. Imported dataset into Power BI
2. Cleaned data using Power Query
3. Created relationships between tables
4. Created DAX measures like:
   - Total Sales
   - Average Sales
   - Total Items
   - Average Rating
5. Created visualizations:
   - Sales by Outlet Size
   - Sales by Outlet Location
   - Sales by Item Type
   - Outlet Establishment Year
6. Created interactive dashboard using filters

## Key Insights
- Total Sales: $1.2M
- Tier 3 outlets generated highest sales
- Medium size outlets have highest sales contribution
- Fruits and Snack Foods are top-selling item types
- Sales increased significantly after 2018
- Average rating is around 3.9

## Conclusion
This dashboard helps Blinkit management understand outlet performance, product performance, and sales growth trends, which helps in business decision making.
